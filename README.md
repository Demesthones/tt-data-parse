# TT-Data-Parse
Easily create local backup of all of your favorited videos, users you follow, and users who follow you.
## Usage
**Prerequisites:** Have a copy of your TikTok data. This can be downloaded from TikTok under Settings > Privacy > Download your Data. Select All Data, and choose the JSON format. Once you receive the data, unzip the file and place it anywhere on your device.

When you launch the app it will detect if the tiktok data file exists in the same location and will use that file if found.

If it is not found, you will be prompted to enter the path to the file. Right click on your data file and click Copy As Path, then paste it into the app.

You will be prompted to save your followers/following users lists.

You will be prompted to save your Favorited Videos.

Wait for the download to finish. This may take some time if you have a lot of videos. Please be aware that videos take up a lot of storage space, so ensure that you have enough space available.
